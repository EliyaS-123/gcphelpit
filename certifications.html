🧑‍💼 Google Workspace certification

CertificationLevelRec. experienceDurationCostValid
Associate Google Workspace Administrator associate ~6 months Super Admin experience 2 hrs (50–60 Q, ~75% pass) $125 see note
Workspace notes: the Professional Google Workspace Administrator cert was retired Dec 31, 2024 — the Associate is now the sole active Workspace credential. Validity is unclear: Google's general FAQ says Associate = 3 years, but a third-party site listed this one as 2 years, and the exam page itself gives no explicit number. Treat it as most likely 3 years, but verify on the exam page before relying on it. Languages: English & Japanese.

🚀 Recommended path: beginner → pro

  1. Foundations (no experience). Grab the free tier + $300 credit and take Cloud Digital Leader. For a Workspace career, get hands-on in the Admin console instead.
  2. First technical cert. Do the Coursera Cloud Engineer certificate + Skills Boost quests → Associate Cloud Engineer (or Associate Google Workspace Administrator for the Workspace track).
  3. Specialize (Professional). Pick a role-based track + its Coursera certificate: Architecture → Cloud Architect (most popular next step); Data/ML → Data Engineer → ML Engineer; Ops → DevOps; Security → Security Engineer; Networking → Network Engineer; App dev → Cloud Developer.
  4. Throughout. Reinforce with hands-on Skills Boost labs, the Architecture Center, Dan Sullivan's study guides, and community Q&A. See the Learn page.
