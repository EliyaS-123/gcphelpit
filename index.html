# Two things that trip up almost everyone

If you only remember two facts, make them these.

💸

Budgets don't cap spending

A GCP budget only sends alerts. It never stops usage or billing. For a true hard stop you must wire a budget's Pub/Sub notification to a function that disables billing.

🔑

Two different "auth login"s

gcloud auth login only authenticates the CLI. Your app's client libraries use ADC — run gcloud auth application-default login too, or you'll get "could not determine credentials."
